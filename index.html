YAAS Studio

YouTube Agentic AI Studio — open source (MIT)

YAAS Studio is a local desktop application that generates short-form videos with AI and publishes them to the creator's own authorized accounts on YouTube and TikTok. It runs entirely on the user's computer: there is no hosted backend and no third-party account is ever accessed.

How it works

  1. The user runs the app locally and opens its web interface at http://localhost:7071.
  2. The app generates a script, images and a video with the AI providers whose API keys the user configured (bring-your-own-key).
  3. The user reviews the result in the Review screen and can regenerate or edit anything.
  4. The user presses Publish for the platform they want. Nothing is ever uploaded without that explicit action.

YouTube integration

Publishing uses the official YouTube Data API v3 with OAuth 2.0. The app uploads only the video the user just generated and reviewed, with the title, description, tags and privacy status chosen by the user in the app, to the channel the user authorized. Refresh tokens are stored locally in the user's machine.

TikTok integration

The app uses Login Kit (scopes user.info.basic, video.publish) to obtain the creator's access token, and the Content Posting API to publish:

StepAPI call
Read the authorized creator and available privacy levelsPOST /v2/post/publish/creator_info/query/
Initialize an upload for the reviewed videoPOST /v2/post/publish/video/init/ with source=FILE_UPLOAD
Upload the file in chunks to the returned upload URLPUT to upload_url
Poll until the post is publishedPOST /v2/post/publish/status/fetch/
  • Only the creator's own account is used — the app never posts on behalf of third parties.
  • Each publish is triggered by a single user click on the video the user generated and approved in the app.
  • The privacy level is selected by the user among the options returned by TikTok; unaudited clients are limited to private (SELF_ONLY) posts.
  • No content is scraped, downloaded or reposted from TikTok, and no automated engagement is performed.

Requirements

Windows, macOS or Linux, Python 3.12, and API keys that the user creates in their own developer accounts. The app is distributed as source code under the MIT license.
